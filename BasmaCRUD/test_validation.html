Instructions de test

  • Formulaire Événement :
    • Laissez le titre vide → erreur "Le titre est obligatoire"
    • Entrez un titre d'1 caractère → erreur sur la longueur
    • Laissez la description vide → erreur "La description est obligatoire"
    • Entrez moins de 10 caractères → erreur sur la longueur minimale
    • Laissez la date vide → erreur "La date est obligatoire"
    • Entrez un mauvais format de date → erreur de format
    • Laissez le lieu vide → erreur "Le lieu est obligatoire"
    • Entrez une capacité non numérique → erreur de format
  • Formulaire Réservation :
    • Ne sélectionnez pas d'événement → erreur "Vous devez sélectionner un événement"
    • Laissez le nom vide → erreur "Le nom est obligatoire"
    • Entrez un email invalide → erreur "L'adresse email n'est pas valide"
    • Entrez un nombre de places non numérique → erreur de format
    • Entrez 0 ou un nombre négatif → erreur "doit être au moins 1"
  • Comportement attendu :
    • Les erreurs s'affichent en rouge sous chaque champ invalide
    • Le champ invalide a une bordure rouge et une animation de secousse
    • Le focus est placé sur le premier champ invalide
    • Les erreurs disparaissent quand vous commencez à taper dans le champ
    • Aucune alerte JavaScript n'apparaît (contrairement à l'ancien système)
